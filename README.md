# AUTOMATHS – versions publiées

Ce dépôt contient uniquement les **versions publiées** de l'application AUTOMATHS
(génération d'épreuves de mathématiques, 6e – Terminale, Cameroun).
Le code source est conservé dans un dépôt privé.

## Installer ou mettre à jour

- **Android** : ouvrir l'onglet [Releases](../../releases), télécharger le fichier `.apk`
  de la dernière version et l'installer. Vos épreuves, questions et réglages sont conservés.
- **Dans l'application** : *Paramètres › Mise à jour de l'application › Rechercher une mise à jour*
  télécharge et installe directement la dernière version.
- **Windows** : télécharger l'archive `.zip` de la dernière version et l'extraire.

## Pour le mainteneur

Chaque version est une *release* d'étiquette `vX.Y.Z` (supérieure à la version installée),
avec ses notes (affichées dans l'application) et l'APK signé avec la clé habituelle en pièce
jointe. Voir `docs/COMPILATION_MAINTENANCE.md` dans le dépôt du code source.
